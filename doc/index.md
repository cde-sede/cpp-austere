# ca reference

_Generated by `tooling/autodoc.py`. Do not edit._

ca is a C++ library written without the standard library, without exceptions and without RTTI, for programs that want every cost visible: no hidden allocation, no hidden failure, no libc or std name reaching the user. Errors are values (`ca::result`), resources are released explicitly (`cleanup()`), memory comes from an allocator each type names, and whatever cannot fail in a correct program traps instead of throwing.

### Layers

The library is built in six ordered layers. A layer depends only on the layers below it, which the include paths make visible (`#include "3-system/file/open.hpp"`), and each layer page of this reference opens with what its layer is for.

| Layer | Contents |
|---|---|
| 1-primitives | the language and the compiler: traits, integers, bits, atomics, hashing, memory primitives, traps |
| 2-vocabulary | value types: `result`, `optional`, `error`, views (`span`, `borrowed_slice`, `sv`), unicode, I/O contracts |
| 3-system | the OS boundary: `ca::sys` wrappers, `ca::syscall`, `errc`, error traces |
| 4-lifecycle | creation and destruction: allocators, arena, heap, `make`, `unique`, contexts |
| 5-collections | containers, strings, maps, lists, paths, formatting, in-memory I/O, reports |
| 6-resources | descriptors, buffered I/O, stdout and stderr, `print` |

Programs include the facade instead of the layer paths: `#include "ca/print.hpp"`, or `"ca/all.hpp"` for everything.

### A first program

```c++
#include "ca/dynamic_array.hpp"
#include "ca/error.hpp"
#include "ca/flush.hpp"
#include "ca/hashmap.hpp"
#include "ca/print.hpp"
#include "ca/str.hpp"
#include "ca/sv.hpp"

[[nodiscard]] static auto count_words(const ca::sv::str text, ca::hashmap<ca::str, int>& counts) noexcept
	-> ca::result<ca::usz> {
	ca::usz total = 0U;
	for (const ca::sv::str word : text.split()) {
		auto slot = counts.setdefault(word.strip(".,"), 0);
		if (!slot)
			return slot.propagate();
		++**slot;
		++total;
	}
	return total;
}

auto main(void) -> int {
	ca::hashmap<ca::str, int> counts{};
	auto total = count_words("the cat saw the dog. the dog ran.", counts);
	if (!total)
		return 1;
	if (!ca::print("{} words, {} distinct, 'the' x{}\n", *total, counts.size(), counts["the"]))
		return 2;
	return counts.cleanup() && ca::flush() ? 0 : 3;
}
```

The habits it shows run through the whole library: every allocation is a `result` to check (`setdefault` may grow the map), views (`sv::str`) are passed by value and never allocate, map lookups by text need no temporary string, formats are checked when the program compiles, and the program releases what it owns and checks that its output was written before it exits.

### Building

`make` builds `build/<compiler>-<mode>/libca.a` (clang++ debug by default; `CXX=g++`, `MODE=release`), `make test` runs the tests, `make matrix` checks both compilers in both modes, and `make gen` regenerates the generated sources and this reference. A program compiles with `-std=c++2c` (clang) or `-std=c++23` (gcc), `-nostdinc++ -fno-exceptions -fno-rtti`, `-I src/lib`, and links `libca.a`.

### Without libc

On Linux x86-64, ca reaches the kernel itself: `ca::sys` makes its syscalls through `ca::syscall` (the vDSO for the clock), formats and reads floats, finds time zones and copies memory without the C library, and defines `memcpy`, `memset`, `memcmp`, `strlen` and the other functions compilers call by name. A program can therefore link without libc at all, with `build/<compiler>-<mode>/libca_runtime.a` (from `src/runtime/`) in its place: the process entry (`_start`, the main thread's TLS, constructors, `exit` and `atexit`), the environment, `malloc` on `ca::heap`, `fork` and `posix_spawn`, and what C++ code compiles to calls of: guards of function-local statics (a recursive initialization traps), `thread_local` destructors (run at exit before static ones), the pure virtual trap, and `operator new` and `delete` on `malloc` (trapping when memory runs out). It also has what libm functions builtins such as `__builtin_fmod`, `__builtin_floor` and `__builtin_sqrt` lower to: the exact ones, whose result IEEE 754 fixes to the bit (fmod and remainder on the x87 fprem loop, rounding, sqrt, fma, fmin/fmax, ldexp, frexp, modf, logb, nextafter, ... for float, double and long double, fma only for float and double), each with glibc's result and errno (`sys::impl` in `3-system/math/impl/`). Transcendental functions (exp, sin, ...) are not provided. It is not part of `libca.a`: it defines what libc's own startup files define, and must not be linked next to them.

```sh
c++ -std=c++2c -nostdinc++ -fno-exceptions -fno-rtti -I src/lib prog.cpp -nostdlib -static-pie \
    -Wl,-u,_start -Wl,--start-group libca.a libca_runtime.a -Wl,--end-group -lgcc
```

`-static` works as well. `-lgcc` is for the program's own code: `-nostdlib` drops libgcc too, whose arithmetic helpers (128-bit division: `__udivti3`) need no libc; `libca.a` calls none. Threads are not supported without libc yet: the runtime's thread keys assume a single thread.
