# ca

_Generated by `tooling/autodoc.py` from `/* @DOC */` comments. Do not edit._

The include facade: what programs include. `#include "ca/print.hpp"` instead of `"6-resources/print/print.hpp"`; the layer directories stay an implementation detail that library code uses, so that layering stays checkable, while users name what they want.

Every header here is generated by `tooling/gen_includes.py`, which every `make` runs; none is edited by hand, and `make matrix` fails when the facade is stale. The names are derived from the tree, nothing configured:

| Umbrella | Covers | Example |
|---|---|---|
| category | each directory directly under a layer, merged across layers | `ca/memory.hpp`: layer 1 memory, `sys` memory and the allocators |
| entity | each header at a layer root, and each header of layers 5 and 6 | `ca/optional.hpp`, `ca/dynamic_array.hpp`, `ca/descriptor.hpp` |
| all | the whole library | `ca/all.hpp` |

A name that is both joins the two (`ca/error.hpp`: `ca::error` and the `errc` codes, messages and names). Tag types come with their constant (`ca/nullopt.hpp` brings `nullopt_t`). `impl/` directories and headers are never listed. Each umbrella names only the headers no other member already includes, so it stays short and never pulls a platform-specific header its owner selects.

```c++
#include "ca/dynamic_array.hpp"
#include "ca/error.hpp"
#include "ca/format.hpp"
#include "ca/memory.hpp"
#include "ca/print.hpp"
#include "ca/str.hpp"

auto main(void) -> int {
	ca::dynamic_array<int> values{};
	if (!values.extend({1, 2, 3}))
		return 1;
	auto text = ca::format("{} values on {} bytes pages", values.size(), ca::sys::page_size());
	if (!text || !ca::print("{}\n", *text))
		return 2;
	return values.cleanup() && text->cleanup() ? 0 : 3;
}
```

No header in ca, facade included, includes a system or standard header, so including any of them never brings a libc or std name into a program; `make leaks` checks it.
